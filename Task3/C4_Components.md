# C4 Model — Level 3: Component Diagram (Внутренняя логика Antifrod System)

## 1. Таблица ответственности внутренних компонентов

| Компонент | Роль в конвейере | Детерминированный / Обучаемый | Описание выполняемой функции |
| :--- | :--- | :--- | :--- |
| **Kafka connector** | Шлюз ввода-вывода (Inbound Gateway) | Детерминированный (Код) | Технический модуль. Осуществляет асинхронное чтение пачек транзакций из топика `incoming-payments` Кафки и отправляет финальные отранжированные статусы в топик `processed-payments`. |
| **Request service** | Сервис сборки контекста (Feature Extractor) | Детерминированный (Код) | Отвечает за подготовку данных для ИИ. Запрашивает из `Operation DB` историю клиента, вычисляет относительные коэффициенты активности на скользящем окне и формирует итоговый вектор признаков. |
| **Antifrod model Core** | Вычислительное ядро ИИ (Model Inference) | **Обучаемый (ML)** | Ограниченный контур ИИ. Принимает очищенный вектор признаков и текст назначения платежа. Модуль RuBERT строит эмбеддинги текста, модель Isolation Forest рассчитывает индекс аномальности операции [0.00, 1.00]. |
| **Operation list provider** | Калибровщик и Бизнес-роутер (Decision Engine) | Детерминированный (Код) | Реализует рабочую точку конвейера. Собирает скоры для всей 30-минутной пачки (150 шт.), сортирует их по убыванию. Назначает ТОП-20 операционным аномалиям статус `Suspended` (для отправки в СБ), а оставшимся 130 операциям — статус `Cleared` (для автоматического выпуска). Является хранителем логики аварийного обхода (Fallback): в случае падения или зависания ИИ-ядра автоматически переключает конвейер на ранжирование пачки по старым детерминированным правилам и эвристикам (If/Else по суммам и пороговым лимитам), гарантируя непрерывность бизнес-процесса. |
