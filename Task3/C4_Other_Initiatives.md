# C4 Model — Level 2: Container Diagram (Инициативы №2 и №10 — Кредитный конвейер МСБ)

## 1. Контейнерный ландшафт Инициативы №2 (Распознавание сканов документов)

* **Контейнер 2.1: Фронт-офис / CRM Кредитования (Внешняя система)**
  * *Роль:* Сбор кредитных заявок за день. Клиент МСБ загружает хаотичный пакет документов (PDF-выписки, фотографии деклараций ИП на телефон).
  * *Взаимодействие:* Накапливает пакеты документов в течение дня и ночью инициирует пакетный Batch-запрос к антифрод-системе.
* **Контейнер 2.2: Батч-оркестратор кредитного конвейера (On-Premise Backend)**
  * *Роль:* Управление ночным технологическим окном (с 22:00 до 08:00). Забирает из архива суточную пачку документов и поочередно отправляет файлы на оцифровку.
* **Контейнер 2.3: Локальный OCR-движок (On-Premise Service, PaddleOCR / EasyOCR)**
  * *Роль:* Вычислительный контейнер распознавания (работает strictly On-Premise для защиты ПДн). Локализует текстовые зоны и переводит картинку в сырую строку символов.
* **Контейнер 2.4: Модуль NER-извлечения полей (On-Premise Service, RuBERT)**
  * *Роль:* Семантический разбор. Пробегает по сырому распознанному тексту, идентифицирует именованные сущности и раскладывает их по ячейкам: ИНН, Выручка, ОКВЭД, Даты.
* **Контейнер 2.5: Шлюз Валидации и ФЛК (On-Premise Backend)**
  * *Роль:* Реализация рабочей точки конвейера. Проверяет извлеченный JSON-массив по 100% детерминированных правил (форматы, типы данных). 
    * Если ФЛК пройден успешно (STP Rate) — данные автоматически сохраняются в Кредитную систему.
    * Если ФЛК упал — пакет отправляется в Интерфейс ручной верификации операторам поддержки.

## 2. Контейнерный ландшафт Инициативы №10 (Двухконтурный антифрод документов)

* **Контейнер 10.1: Контур А — Графический анализатор пикселей (On-Premise CV Service, CNN/ELA)**
  * *Роль:* Поиск фотошопа. Принимает сырое изображение страницы документа из Батч-оркестратора. Анализирует артефакты сжатия и пиксельные аномалии. Если уверенность в ретуши > 30% — генерирует тепловую карту (Heatmap) манипуляций и ставит флаг риска `Suspended_Graph`.
* **Контейнер 10.2: Контур Б — Логический валидатор полей (On-Premise NLP Service)**
  * *Роль:* Поиск смыслового фрода. Принимает извлеченный JSON-массив реквизитов из Инициативы №2. Через коннектор отправляет детерминированный gRPC-запрос во внешние государственные базы данных по API ФНС / ГИР БО.
  * *Взаимодействие:* Сверяет «значение в значение» ОКВЭД, ИНН и выручку из документа с официальным ответом налоговой. При любом несовпадении или семантическом бреде (поставка бумаги на 1.5 млрд для ИП по ремонту авто) ставит флаг риска `Suspended_Logic`.
* **Контейнер 10.3: Диспетчер эскалаций СБ (On-Premise Backend)**
  * *Роль:* Сборщик алертов. Если сработал флаг `Suspended_Graph` или `Suspended_Logic`, контейнер блокирует автоматическую отправку заявки на кредитный скоринг и принудительно перенаправляет кейс (вместе с тепловой картой и логом нестыковок ФНС) в Службу безопасности банка.
* **Контейнер 10.4: CRM Интерфейс Службы безопасности (Frontend)**
  * *Роль:* Рабочее место офицера СБ для ручного разбора подозрительных заявок и вынесения окончательного человеческого вердикта (Ground Truth) по факту предотвращения ложного запроса кредитного лимита.
